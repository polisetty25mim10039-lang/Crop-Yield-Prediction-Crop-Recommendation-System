# Crop-Yield-Prediction-Crop-Recommendation-System
Command Line Interface (CLI) AI/ML system with 2 models, which takes data as input and predicts it: (1) crop recommender (classifier model: Random Forest with soil N-P-K, pH, weather features), and (2) yield predictor (regressor model: state/season/crop/area features) Custom feature engineering, input checking, logging, and unit tests.
